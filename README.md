Во прилог е мојот проект по предметот Системи базирани на знаење:

Овој проект е паметен асистент за патувања кој им помага на корисниците да пронајдат идеална дестинација за одмор 
врз основа на нивниот буџет, посакуваната клима и типот на одмор.

Системот користи JSON база на знаење (knowledgebase.json) со над 25 глобални и регионални дестинации. Врз основа на корисничкиот внес,
бекендот врши динамичко филтрирање и ја издвојува главната препорачана дестинација, како и сите останати можности во истиот ценовен ранг.
--------------------------------
Framework: .NET8.0           
Јазик : C#
Data Source: JSON
JSON Парсер: Newtonsoft.Json
UI: Bootstrap, CSS3, HTML5
-------------------------------
Апликацијата се стартува преку PowerShell локално во фолдерот со команда dotnet run, креира localhost и го внесуваме истиот во browser
